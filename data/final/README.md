# Final Data

Group-level, baseline-corrected datasets ready for statistical analysis. These are produced by the aggregation cells at the end of notebooks `002` and `003`, which read every subject folder under `data/processed`.

## Available Datasets

- `ecg_metrics/group_level_blc_ecg_metrics.xlsx`: HRV and RSA features for all dyad members, with baseline values and baseline-corrected values (see `data/final/ecg_metrics/README.md` for the full schema).
- `eda_features/group_level_blc_eda_features.xlsx`: EDA-derived features for all dyad members, including raw, baseline, and baseline-corrected values (`data/final/eda_features/README.md` documents the columns).

Both files are in long format: one row per dyad member and segment, with `subject_id` set to `{subject}_{role}` (e.g. `T001_child`). `Baseline` rows are dropped after being used as the correction reference, so each subject contributes four rows (`DCP`, `IDP`, `NDCP`, `Recovery`).

## `neuro-behavioral_data.xlsx` — not currently produced

The original project also published a wide-format workbook that merged the datasets above with behavioral data, generated by `004_reformat_final_datasets.ipynb`. That notebook has not been adapted to the TECH project: it pivots on story names (`Story 1`–`Story 5`) and reads `data/behavioral/filtered_data_v3 (with ASAs).xlsx`, neither of which exists here. Until it is reworked, `data/final` contains only the two long-format files listed above.
