# Project Documentation

Reference materials, decision logs, and narrative reports that complement the code outputs. Keep this folder updated with interpretive documents.

Current contents, all carried over from the original project this pipeline was forked from and therefore describing that dataset rather than TECH:

- `Mindware Missing Data Report.docx` – overview of missing and unusable recordings.
- `Mindware event file modifications.docx` – log of manual corrections made to event files.
- `ECG Preprocess Data Quality Log.docx` – per-subject notes from the ECG preprocessing QA.

Add TECH equivalents here as the data quality picture for this project takes shape.

Machine-generated reports are not stored here: `001_data_preparation.ipynb` and `scripts/check_raw_data_consistency.py` write theirs to `reports/`, which is excluded from version control.
